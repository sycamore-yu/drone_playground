# 配置归属

后续由任务 01 建立实际配置入口，复用 `ml_collections`/作者配置并保存完全解析后的结果。
任务、算法、动力学、传感器和实验组合分别放在对应子目录；一个实际配方只维护一个来源。

首轮依赖候选来自历史验证：Brax 0.14.2、JAX/JAXlib 0.9.2、Flax 0.12.6、Optax 0.2.8、
MuJoCo/MJX 3.14、rscope 0.0.8。新项目使用独立 Pixi，Python 3.13 是兼容 MID-360 依赖的待验证选择。
正式 `pixi.lock` 在依赖求解与相关真实测试通过后生成，历史 Python 3.14 的报告保留原身份。

模型、动作接口、任务协议和数据集身份作为独立字段。四模型研究只展开实际支持的受控切片。
