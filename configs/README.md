# 配置归属

任务 01/02/03 已建立实际配置入口：四份 `experiments/*.json` 配方由 CLI 读取并保存解析后的结果。
任务、算法、动力学、传感器和实验组合分别放在对应子目录；一个实际配方只维护一个来源。

首轮依赖候选来自历史验证：Brax 0.14.2、JAX/JAXlib 0.9.2、Flax 0.12.6、Optax 0.2.8、
MuJoCo/MJX 3.14、rscope 0.0.8。独立 Pixi/Python 3.13.15 已完成真实训练和依赖检查，
完整锁定写入 `pixi.lock`，历史 Python 3.14 报告保留原身份。MID-360 本身仍属后续接入任务。

模型、动作接口、任务协议和数据集身份作为独立字段。四模型研究只展开实际支持的受控切片。
