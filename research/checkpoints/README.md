# 参考训练模型与评测记录

本目录保存已有实验产生的冻结权重、训练配方和原始评测报告，以便进行模型迁移、基线比较和参数研究。

| 内容 | 位置 |
|---|---|
| 权重索引、实验条件与参数超信息 | [manifest.json](manifest.json) |
| 冻结模型 | `weights/`，22 份、约 26.35 MB |
| 逐回合评测 | `reports/`，22 份原始报告 |
| 汇总 | `reports/formal-summary.json`，记录 26 个条件引用、2600 个回合 |

## 参考实验结果

以下为相应来源条件下的冻结评测，三种子每种子 100 次：

| 算法与任务 | 三种子完成次数 | 成功回合 RMSE（m） |
|---|---|---|
| PPO-tracking | 100/100/100 / 100 | 0.0972, 0.1073, 0.1241 |
| PPO-racing | 100/100/100 / 100 | — |
| SHAC-tracking | 100/100/100 / 100 | 0.0724, 0.1161, 0.1484 |
| SHAC-racing | 100/100/100 / 100 | — |
| APG-tracking | 100/100/100 / 100 | 0.0390, 0.0365, 0.0336 |
| APG-racing | 100/100/100 / 100 | — |

感知导航参数包含 Depth 三种子及 PointCloud 一个种子。Depth 的动态 D03 在其中一次为 `22/25`；PointCloud 动态 D03 为 `13/25`。完整静/动及扩展场景统计见 `reports/`。这些参考模型的感知网络、动力学及传感器可能与当前 Crazyflow 实验不同，因此加载时使用实际模型与观测／动作合同。

模型文件中的部分 `.pkl` 是原始完整训练状态。参数转换应针对明确选定的模型进行，并重新验证前向运行；新训练收敛仍由 [Spec C1—C6](../../docs/spec.md) 判断。

## 来源

`manifest.json` 保存每个模型的来源路径、训练配置摘要、权重摘要和对应报告。此处保留的是已有实验资产；当前项目的规范为 `docs/spec.md` 和 `docs/adr/`。
