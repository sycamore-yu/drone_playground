# 评测协议与结果含义

方法实现、预算完成、任务完成率和质量阈值分别记录。正式结果以冻结参数、完整回合分母、具名场景和原始终止事件为依据；运行进程正常结束只证明该次执行结束。

## 正式矩阵

当前公开矩阵由 `verification/final-acceptance/selection.json` 的30个方法／任务单元唯一确定，覆盖29个评测运行、488回合及245份正式回放。点云静态和动态导航共享一个32回合运行，按场景前缀拆分为两格。

控制学习方法每任务评测32回合，记录完成次数和位置均方根误差。质量判断同时使用完成率与0.25米误差阈值。原生规划器控制任务每格仅2回合，完成次数与误差各自保留；采样规模及任务适配差异限制跨方法比较。训练种子、评测重置种子、命令和参数摘要均记录在证据中。

SHAC 竞速明确使用 BPTT 策略参数热启动，再执行320次真实 SHAC 更新。点云控制任务使用完整 PointNet/GRU 架构及0.02点坐标尺度的控制迁移配方。点云导航使用公开论文重建方法第30000次更新冻结参数，命令速度为4、6、8、20米/秒。详细边界见[点云方法说明](research/pointcloud.md)。

PPO、BPTT、SHAC 的正式导航格对应每格4096次交互的工程短训练。后续调参以独立运行身份管理，本次公开表保留选定历史结果。

## Navigation

权威几何位于 `assets/scenes/navigation/catalog.json`，包含四张静态场景和四张动态场景。场景尺度为100×40米，名义起终点距离96米，到达半径0.5米。第二版协议时限300秒、名义速度上限20米/秒，协议文件位于 `benchmarks/navigation/v2/`。

到达、碰撞、边界越界、数值失败和超时构成明确的终止分类，同一步的失败事件优先于到达。碰撞、传感器及净空使用相同几何和运动时刻。各方法按自己冻结的策略／物理时钟检测事件和结束回合；正式回放保留截止终止状态的活动片段。

通用导航每难度2回合，共6回合，困难组包含两张具名场景；完整场景的重复次数必须从逐回合明细读取。点云导航每种速度覆盖全部八张场景。固定几何跨训练、开发和留出划分共享，种子差异所验证的是具体重置或延迟条件下的稳健性。

成功回合的到达时间与包含失败惩罚的受约束时间分开统计。命令速度、实际均速、峰值速度和名义速度上限分别记录。20米/秒上限本身不能证明20米/秒任务成功。

## 参数选择与信息边界

开发集负责选择参数；留出评测使用选定参数并验证其摘要。历史论文重建、控制迁移和导航域适配各有自己的训练数据与选模规则。新的训练域、损失、输入尺度、传感导数或执行时序写入具名配方。

策略推理只使用声明的观测。训练期几何损失、碰撞判定、初态安全采样和规划器内部模型分别说明来源；额外地图、未来障碍轨迹或隐式避障控制器必须显式登记。

## 证据与保留

每个正式运行保存解析配置、源代码身份、依赖、随机种子、原始报告、选定参数及回放。整理过程可迁移主机路径，原始文件摘要与迁移记录须分别保留。数值结果、参数字节和正式回放在本次迁移中逐项核对。

重新汇总使用 `scripts/tools/summarize_final_acceptance.py`；它验证实际产物，遇到缺失文件、摘要不符或分母缺项时退出失败。成功产物独立备份；表外失败大文件可以按明确清单清理，正式矩阵继续保留全部失败事件。
