# 版本 3 可组合架构与现役入口

日期：2026-09-28。用户授权破坏性重组与本地提交。主基线 1b93534，点云来源 dbb660c。

采用 JAX 原生实现优先路线，源代码提供实现和数值参考。现有原生规划器和 acados 作为有边界的基线适配保留。

方法配方与环境预设统一为公开装配入口；rl/diffrl 浏览目录合并为 learning。实际动力学使用 dynamics 命名；预测模型归方法；导数选择归 algorithm.gradient。场景统一称 navigation，原几何和记录身份可核对。

共享执行层负责单次命令应用和完整物理推进；共享运行层分别提供 JAX 批量闭环和外部进程闭环。网络移出训练目录；任务、传感器和观测进入 environments 子域。实际实现见 docs/architecture.md。

旧配置迁移采用显式复制工具，现役执行只消费版本 3。LOTF 固定子模块由统一来源缓存取代，机体/场景资产随固定源码取得。控制比较重点为轨迹跟踪，传感器目标为现实测量特征。

用户确认未来方法为 LOONG 与 AERO-MPPI；这两项及 AC-MPC 的完整 JAX 实现分别安排，来源表明确标记待实现。新增配方名称需对应真实可运行实现。

PPO 各核心任务、两原生导航方法、两 MPC 和点云路径承担本次验收。每项记录其实际预算和质量，短训练通过与最终策略达标分别判断。所有原运行和原点云训练继续留在原工作树。
