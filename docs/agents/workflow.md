# 智能体执行与交接

目标是让研究者随时确认当前动作、最近证据和下一步。执行沿既有 Chat On Steroids / dsh
会话进行；项目文件保存跨会话事实。这里规定闭环，不新增多智能体编排服务。

## 每次开始

读取 `docs/status.md`、当前任务单、相关模块说明，核对 Git 工作树、会话和活动进程。
以既有运行的 `run_id`、检查点与日志恢复；保留其他任务正在修改的文件和服务。
当前任务无真实接口依赖时直接执行，事实查询由智能体完成。

## 一次可交付工作

领取任务并记录执行者/会话 → 明确此次要证明的外部行为 → 修改最小必要范围 →
跑相关测试和真实任务 → 保存证据 → 审查结果 → 更新任务单和当前进度 → 本地提交。
每个任务完成一条从输入到用户可观察结果的完整路径，代码目录按模块归属。

测试通过依据命令、退出码和输出。实现者与审查者分别检查代码正确性和规格符合性，
共享接口/梯度/评测变更需要独立复核；普通小改动按风险选择验证量。

## 研究者看到的三个入口

1. `docs/status.md`：现在在做什么、上次完成什么、当前任务、进程/会话、证据位置和下一步。
2. TensorBoard：训练回报、任务质量、动作/梯度统计、预算消耗和吞吐。评估与训练曲线分组。
3. rscope：同一个运行的完整轨迹，固定初态下初始化/中期/最终行为及失败回合。

任务和指标均附运行标识。浏览器里的曲线和桌面里的轨迹必须能回到同一配置与代码版本。

## 更新时机

开始任务、启动/退出训练、形成新检查点、失败诊断、任务验收和交接时立即更新文件。
长命令启动前写清命令、进程标识、日志和预计下一种输出。
运行记录模块在首阶段实现低频更新，工程默认 60 秒一条；记录阶段及已用预算。
编译时显示“编译中”和耗时，训练时显示实际交互数；编译进度不制造百分比。
最近更新时间超过配置阈值（默认 180 秒）显示“待核对”，再核对 PID/启动时间/日志。
进程活跃、日志有更新和任务有实质进展分别显示。

上述更新默认值属于本项目运维选择，实施时集中配置。当前项目只完成文档与任务目录，
首阶段运行模块尚未实现定时写入；Markdown 本身不会在后台执行任务。

## 最小运行证据包

```text
experiments/<run_id>/
  manifest.json         代码/任务/协议/配置/种子/预算/设备
  resolved-config.*    完整解析后配置
  command.txt          原始启动与复现命令
  state.json           阶段、进程启动标识、最近更新、步数、会话
  console.log          完整命令输出
  metrics/             TensorBoard 事件与机器可读标量
  checkpoints/         策略、归一化及恢复所需状态
  eval/                固定试次逐回合结果与汇总
  rollouts/            rscope 记录、模型资源和场景快照
  result.json          完成/失败/取消、实际预算、验收结论
```

这是首阶段将交付的目录契约。检查点用于推理和用于精确续训分别标识；恢复能力需单独测试，
不能仅凭保存了网络参数就声称恢复了优化器、随机数和任务进度。

## 失败和并行

失败先留原始日志与最小反例，提出能区分原因的一项检查，再做有证据的修正。
同一个假设的重复失败触发重审和范围缩小；禁止为了绿色结果减少正式预算或放宽评测。
单个算法质量不足记录低分，接口完整的独立任务继续。
真正的依赖是缺少输入、共同接口或冻结协议，不把某方法高成功率设置成全局开工条件。

并行优先用于独立源码适配、文档或 CPU 测试。共同接口由单一执行者修改；GPU 重训练按预算排队。
已休眠会话先恢复，恢复失败记录原因和接替关系；任务单只保留一个当前 Owner。

## 交接记录

每次结束留下：任务与分支/提交、已经验证的结论、活动进程及运行标识、最近日志、
剩余问题、下一条已验证命令。中断时优先从 `state.json`、日志和检查点核对实际状态。
能继续的独立工作照常推进；需要研究决定、额外资源或外部发布时向用户提出具体问题。

Matt 的纵向任务单提供依赖和可演示工作粒度；Anthropic 提供持久进度、功能清单和真实验证；
OpenAI 提供仓库知识索引与可观测反馈；Simon Willison 强调执行与测试；Addy Osmani 强调理解与验收。
本项目采用已有会话工具、Git、Markdown、Brax 回调、rscope 和 TensorBoard，避免再搭一个通用工作流平台。
