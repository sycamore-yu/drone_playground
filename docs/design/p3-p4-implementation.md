## 实验前冻结

- 跟踪任务继续 P2 奖励/观测/初态/时域。PPO 预算分别 2097152/4194304 次交互；APG 655360。
- SHAC 先用 64 个环境、32 步窗口、320 次更新，共 655360 次交互；调整配方产生新版本，保留旧结果。
- 竞速先采用作者已有“参考样条 + 姿态策略”结构，门序 [1,2,3,4,2]、原生方向/门框/碰撞规则作为独立成功判定。
- 三方法初版共享 18.75 秒作者样条作为参考、43 维跟踪观测、姿态动作；30 秒最大回合。
- 竞速学习奖励须具名为参考跟踪奖励；原生稀疏奖励继续记录，避免将轨迹学习误称为自由最短时间规划。
- 竞速 PPO 4194304 次交互；APG/SHAC 655360 次交互。先冻结初版配方，必要调优另建版本。
- 开发集 32，跟踪选模按完成数/误差；竞速在首次训练之前冻结选模顺序为完成数→平均门进度→误差，避免短暂悬停因短回合误差较小而胜过接近完赛的策略。留出集128，在新进程加载冻结检查点。Level 0 固定赛道，随机种子用于扰动而非声称128条不同赛道。
- 单运行墙钟预算 3600 秒。实际交互、初始化/编译/训练/评估/写盘分别记录；到限明确保存状态，不减预算冒充完成。
- 学习模型与评测模型首轮相同。竞速主结果使用作者 first_principles/cf21B_500；其他模型作为标明的辅助实验。
