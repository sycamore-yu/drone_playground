## 关键修正及对应证据

方法配方中重复的算法/网络/训练配置曾遮蔽组件组重选。现仅保留真实配方差异，十份默认方法解析值在清理前后相同，见 [配方去重](recipe-deduplication.json)。随后发现竞速/随机跟踪环境默认动力学丢失，按原始配方恢复；新增10组公开环境与源快照逐项等价测试，竞速PPO及两种MPC在新运行重验。

执行设备与采样预测设备分别约束。修复前的诊断运行实际在GPU推进物理；修复后 `architecture-v3-sampling-source-v3` 记录CPU物理与GPU预测。

新增命令延迟队列在训练自动重置时需要逐环境清空。测试注入一个世界完成、另一个继续，核对新回合获得清空后的队列，同时保留终止转移诊断。

SUPER 地图冷启动超过原20秒门槛时，原运行完整保留为失败；冷启动改为90秒、请求110秒后新运行完成。仿真任务时限保持40秒。

Pixi 对本地动态打包元数据的版本推断导致锁定安装失败。已添加静态版本元数据补丁并记录提交/补丁摘要；14:34的 `pixi-locked-2.log` 记录锁定安装成功，`source-cache-verify-2.log` 记录固定提交和补丁核对。较早的 `pixi-locked-final.log` 是修复前失败记录。补丁涉及打包声明和继承的MuJoCo依赖范围。恢复会话重新安装调用被工具安全状态检查拦截，原安装证据单独保留。

数值失败边界在新执行接口进行故障注入；两个数值异常回归和SHAC检查点测试已更新到版本3公开契约。命令入口另外验证三个脚本的 `--cfg job`。

恢复时新增三个冻结配置反例：仅改一个动力学字段或挂载整个动力学组时，原实现误用默认跟踪任务替换竞速；仅改计算设备时，原动作延迟被默认零值覆盖。现在以保存配置为底，仅应用显式字段或配置组，整套环境选择仍保持明确语义。原反例记录在 `red-recovery-overrides.log`，修复后定向回归37项通过、3子测试通过。

LSY MPC的源码补丁同步更新到新导入路径。补丁反向应用恢复上游源码摘要，正向应用恢复当前源码字节；LSY任务侧一并通过该双向检查，详情见 `source-patches-verified.json`。
