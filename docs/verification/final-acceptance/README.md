## 配方与判据

导航第二版的时限为300秒，原生规划器名义速度上限20米/秒；点云导航另含4、6、8、20米/秒命令速度。场景几何沿用已验收navigation八场景，标准学习／原生方法使用静态或动态三难度、每难度2回合；点云固定场景评测覆盖八场景各四速度。原协议40秒结果作为历史证据保留。
PPO、BPTT、SHAC和本次点云控制迁移的训练均启用逐环境、逐回合25–50毫秒均匀命令延迟；延迟在500赫兹物理时钟上向上取整，实际26–50毫秒。评测保持冻结时序。原点云50000更新训练保持原配方，已运行的历史交互按原无附加传输延迟身份记录。
悬停与跟踪采用原完整时长、完成率至少90%且完成回合平均位置均方根误差至多0.25米；竞速使用原Level0有向过门次序[1,2,3,4,2]和原失败判据。留出初始条件使用30000起始种子；当前结果对应单个训练种子的已选策略。
评测在成功、碰撞、越界或时限事件后停止该回合；JAX批次全部终止后跳过策略、传感器与物理计算，静态数组中的无效填充在回放导出前剔除。标准PPO/BPTT/SHAC控制评测各保存完整32回合数值报告和固定四例加最差例共5份回放；其余本次评测保存全部回合回放。

## 训练身份与实际预算

PPO三控制任务各新增2097152次交互；BPTT和SHAC各新增655360次交互；点云三个控制迁移各1024次更新、262144次交互。PPO跟踪／竞速、BPTT跟踪／竞速复用经旧协议实测验证的历史参数。SHAC竞速的冷启动失败保留，最终为BPTT热启动后320次真实SHAC更新，验收采用更新后的655360步权重。
学习导航每方法、每静态／动态环境完成4096次实际交互，验收明确使用4096步权重。开发集平分时曾选择零步权重，因此正式工程检查单独指定已更新权重。六组均为0/6到达、6次碰撞，训练收敛属于本次用户允许保留的质量事项。
点云控制迁移保留5400条射线、完整PointNet和GRU、加速度输出及质点滞后动力学，独立配置network=paper_pointnet_gru_conditioned将编码器输入坐标乘0.02。测得原点云嵌入范数299.656、状态嵌入6.450，循环状态饱和58.85%；该条件化解除状态反馈受抑制的问题。坐标物理单位、测量、几何和回放保持米。原论文重建配方默认尺度1.0，两个实验身份分开。
原论文训练开发集选中30000更新权重经摘要验证迁入新主线，32格导航为29次碰撞、3次超时。静态16格为15次碰撞、1次超时；动态16格为14次碰撞、2次超时。该结果属于30000/50000更新阶段，完整50k源运行独立保留。

## 原生方法接入与实证修复

SUPER和EGO-Planner的三控制任务使用显式时间参考到滚动目标适配器（5赫兹目标、0.6秒前瞻），真实轨迹由统一位置控制器执行。EGO交互目标高度原被固定为1米，补丁保留收到的三维目标。SUPER亚米级控制动作对轨迹初始时间数值敏感，补丁仅在控制迁移开关下改善初始猜测，目标与约束保持原实现。两补丁及项目自管构建入口位于native_planners/patches与setup.sh。
竞速原起飞位置低于SUPER膨胀地面，原生输出为零的v1/v2结果完整保留。v3以显式垂直位置接管先升至0.8米，保留原起点、原物理计时及过门判据，直到原生轨迹接管；备用控制帧数、原生指令和轨迹数分别记录。最终两方法各2个竞速回合均有真实原生输出，任务失败继续保留。
导航使用预设目标分支及关闭的控制初始化开关，前述控制补丁未改变其数值路径；复用已有20米/秒、300秒协议实测：SUPER静态／动态各6/6到达；EGO静态／动态各6次碰撞。
导航可微训练中的非数值梯度源自未命中射线分支的sqrt(0)导数。四类图元均建立先失败后通过的反例，修复保持前向交点结果，对有效交点与有限差分一致。BPTT和SHAC新运行均完成真实参数更新。
