# 正式验收证据

本目录固定2026-09-29六方法、五任务历史基线，覆盖30个单元、29个评测运行和488回合。汇总表见[项目首页](../../../README.md)，完整精度的数值、参数身份和回放索引以 [evidence.json](evidence.json) 为准。

## 文件职责

| 文件 | 含义 |
|---|---|
| [selection.json](selection.json) | 每个方法／任务唯一对应的评测运行与训练来源 |
| [evidence.json](evidence.json) | 从实际产物重建的结果、参数摘要、解析配置与回放索引 |
| [commands.md](commands.md) | 原始训练与评测命令；重跑时更换运行标识 |
| [replay-readback.json](replay-readback.json) | 迁移后重新核验245份回放、场景加载、时间与终止位置，并验证六个公开回放入口 |
| [source-hashes.json](source-hashes.json) | 该历史验收时的源码摘要；当前主线源码另按Git提交识别 |

所选评测与参数仍保存在根目录的 `experiments/`。整理过程只重定位路径元数据；原始数值、选定参数字节和正式回放逐项核对。原始文件与整理前源码保存在项目外的独立备份，迁移后检查结果见 `../release-cleanup.json`。

## 结果范围

12个学习控制单元均完成32回合留出验收。控制任务使用原完整时长，质量标准包括至少90%完成率和完成回合平均位置均方根误差至多0.25米；竞速沿用Level0有向过门次序 `[1,2,3,4,2]` 及原任务事件。原生控制任务每格2回合，完成数、误差和质量状态分别记录。

PPO三个控制任务各新增2097152次交互；BPTT和SHAC各新增655360次；点云控制迁移各1024次更新、262144次交互。PPO与BPTT的部分任务使用历史参数热启动；SHAC竞速使用BPTT热启动后320次真实SHAC更新，正式验收选择更新后的参数。

学习导航六格各训练4096次交互，正式记录为0/6到达、6次碰撞。标准学习与原生导航各使用三难度、每难度2回合。SUPER静态、动态各6/6到达；EGO-Planner各6次碰撞。完整逐场景分母来自原始报告。

点云导航使用第30000次更新冻结参数，八张场景各评测4、6、8、20米/秒，共32回合：静态15次碰撞、1次超时；动态14次碰撞、2次超时。原论文50000次目标训练保持独立。点云控制迁移采用完整5400射线、PointNet/GRU和0.02输入坐标尺度；其来源与重建假设见[点云说明](../../research/pointcloud.md)。

导航第二版时限300秒、名义速度上限20米/秒、到达半径0.5米。学习控制训练采用25—50毫秒逐回合随机传输延迟，按500Hz物理时钟向上量化。原论文重建参数按其冻结时序解释。

原生控制迁移采用5Hz滚动目标、0.6秒前瞻与统一轨迹跟踪器；竞速起飞阶段显式先升至0.8米再交给原生轨迹，原计时与过门判据继续生效。备用控制步数与真实原生输出分别保存。两项控制迁移补丁见 `native_planners/patches/` 和[集成说明](../../../native_planners/README.md)。

当前基线对应一个训练种子的选定策略。训练预算、输入、模型、初始化和原生适配存在明确差异，完整科学比较需要独立制定一致的实验条件。
