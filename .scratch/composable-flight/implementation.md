# 可组合平台与 LOTF 实施计划

> 执行方式：用户于2026-09-26批准规格并要求在当前会话完整实现。主执行者按模块直接完成，相关测试先失败再通过，最终统一交付训练结果。

**目标**：Hydra组合已有学习/优化控制与四动力学，并完成LOTF混合梯度悬停及八字训练。
**架构**：策略、统一控制器、动力学、场景/观测/任务独立构造；训练配置为算法、网络、目标、运行。
**技术栈**：现有Python3.13/JAX0.9.2/Brax0.14.2；Hydra配置；锁定原生LOTF作为局部依赖。
**规格**：[spec.md](spec.md)。

## 全局约束与裁决

- 用户确认五份模块工作单，整体迁移与两任务共同交付；无需逐模块等待用户再次验收。
- 当前功能分支 `implementation/composable-lotf`，基于 `bd14468`。保留现有工作区与Pixi可编辑路径，已有记录和查看器不迁移。
- 原LOTF锁定 cba6e5370773ace8a08107f02810eecabf16c793，GPLv3；通过有原许可证的固定子模块复用，不重标许可证、不对外发布。
- Notebook悬停：200环境×200更新×150步=600万交互，学习率5e-3余弦；八字：300×300×250=2250万交互，学习率1e-3余弦。
- 作者Notebook默认简化前向，本轮按已批准规格切为高保真前向、解析反向、学习残差关闭；除此之外网络512×512、初态、动作、时延和损失保持Notebook。
- 同一JAX体系复用作者BPTT数学及更新；记录旧JAX/Flax与当前版本的兼容差异。
- 训练种子0；本项目开发32/留出128。报告完整回合、误差、失败和稳态指标，不将存活直接解释为高精度策略。
- 每个正式任务预算冻结后运行；若异常中断，保留快照和日志；配置更改使用新运行版本。
- 训练实际耗时上限每任务7200秒；质量低分保留，不放宽原任务终止或伪造训练结果。

## 重点风险

1. 策略输出顺序/单位不同：姿态+推力与推力+角速度分开声明，错误组合在启动时拒绝。
2. LOTF控制器和模型已内嵌：统一组合只执行一次低层控制，子步数与上游相同。
3. 自定义导数携带PRNG/整型状态：当前JAX零切向量规则独立测试，改变仅限兼容所需。
4. 模型和场景替换后原轨迹语义变化：迁移前后固定随机数/命令进行逐步对照，旧检查点读取显式版本化。
5. 模型编译/训练后处理影响可恢复性：完整状态快照含优化器/随机数/环境/更新数，独立进程恢复及评测。
