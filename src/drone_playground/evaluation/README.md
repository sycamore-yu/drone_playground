# 评测模块

`tracking.py` 已实现冻结策略的完整试次评测，失败后冻结状态、保留失败转移并停止继续计分。
固定开发/留出试次与参数内容哈希在报告中记录，通过真实任务接口执行并聚合事件。
各任务保留原生评价规则。报告全部试次、失败分母、运行身份、质量结果及独立重载证据。

`execution.py`统一冻结网络与`optimization.py`在线求解，`racing.py`按原生门序判定完成，
`lotf.py`报告完整回合、全程误差和最后一秒误差。LOTF异常物理状态计数值失败并保留末个有限姿态，
未定义的数值转移回报记0并显式标注；异常试次仍保留在完整分母。
默认评测沿保存的环境，`evaluation.environment=experiment`显式选择新的兼容模型。
